# 🍕 The Great Pizza Analytics SQL Project  

This project is part of the **21 Days SQL Challenge** by **Indian Data Club × DPDzero**.

I worked as a data analyst for IDC Pizza and explored their sales database to generate insights using SQL.

---

## 🚀 Project Overview

This mini project includes:
- Database setup
- Data exploration
- Filtering & transformation
- Joins and aggregations
- Sales insights and business analytics

All SQL queries are included in the submission CSV.
